## Contents

- `latex/` — full paper source (`main.tex`, `sections/*.tex`, `appendix.tex`,
  `related_work.tex`, `refs.bib`, `main.bbl`), 5 figure PDFs (TrueType-embedded,
  matplotlib `pdf.fonttype=42`), built `main.pdf`.
- `sim/` — simulation platform `autonomy_sim` (env, estimators, scenarios,
  aggregation, directed-information tools), 122 tests (all green at snapshot
  time), campaign runner `run_matrix.py`, report generator `make_report.py`,
  figure generator `make_figures.py`, estimator checks, sensitivity-arm
  analyses, four SPEC documents.
- `sim/runs/20261017_full/` — **authoritative campaign data** (7.1 MB, 146
  files): per-arm `results.csv` + NDJSON run bundles + manifests +
  auto-generated `report.md`. Campaign: main matrix 2,880 runs (2,520
  CONFIRMED + 360 INCONCLUSIVE out-of-window defense cells + 0 REFUTED);
  full registry 11,250 counting bundles (pool (i) 5,760 + 2,880 stress;
  pool (ii) 7,200 + EXEC-1 90) — see paper Appendix N for the exact
  counting arithmetic.
- `refs/manifest.md` — verified-bibliography ledger (112 entries with
  verification channel per entry). Third-party PDFs are not redistributed.

## Reproduction

```bash
cd sim && python3 -m unittest discover -s tests -q        # 122 tests, ~2 min
cd sim && python3 make_figures.py --root runs/20261017_full --out ../latex/figures
cd latex && pdflatex main.tex && bibtex main && pdflatex main.tex && pdflatex main.tex
cd sim && python3 run_matrix.py                           # full campaign (hours)
```

Seeds are deterministic: `seed = 30000 + 1000·s + 97·c + r` over registered
(scenario, configuration, replication) coordinates; NumPy PCG64.
