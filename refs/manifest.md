## K. 检索方法备注（可复现性）

1. **arXiv 条目**：以 `arxiv.org/search` 站内检索或 export API 确认 id 后下载 `https://arxiv.org/pdf/<id>`；**所有 id 均经脚本内容核验**——初期凭记忆填写的 8 个 id（1909.02635、2205.05131、2209.13215、2301.11575、2310.07407、2303.10436、2404.02014、2006.02670）全部核验失败并弃用，此为"必须核验"之直接教训。
2. **非 arXiv 条目**：Semantic Scholar / Unpaywall / Crossref / OpenAlex API → 出版社 OA 直链 / 机构仓库 / 作者主页 / Wayback Machine 原始字节快照（`id_` 后缀）。
3. 已知不可达源（本环境）：PhilArchive/PhilPapers（Cloudflare）、ScienceDirect、UCL Discovery、PMC（reCAPTCHA）、OAPEN 直连、Bing/DDG 爬虫（验证码/JS）。
4. 每份 PDF 的核验证据（首页文本摘录）见 `refs/notes/verify_log.md` 及各 batch TSV。
5. **渠道白名单/黑名单**：白名单=出版社官方 OA、机构/学科仓库、作者主页自存档（含其 Wayback 快照）、大学出版社预览、Wayback 原始字节快照；黑名单=sci-hub 等盗版站、kenud/sciarium/vdoc 等盗版书库、**出处元数据缺失的匿名批量语料**（如 archive.org "wikipedia-scholarly-sources-corpus"，2026-10-04 评估后排除——文件数与 DOI 组织错乱、无 creator/license/source 字段）。
